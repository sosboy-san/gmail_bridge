いつものメールを、
自分のGmailへ。

Gmail Bridgeは、外部メールサーバーのIMAPメールをGmail APIで取り込むPythonアプリです。Linux上のPython環境やDocker環境で、利用者自身が管理・運用します。QNAP NAS / Container Stationでの運用実績があります。

公開コードと個人用OAuthについて

このサイトに対応する「Gmail Bridge」OAuthアプリは、所有者本人の個人運用専用です。一般向けのログインサービスは提供していません。公開コードの利用者は、各自のGoogle Cloudプロジェクト・OAuthクライアント・認証情報を用意してください。所有者の認証情報は配布しません。

外部メールにも、Gmailのフィルタを

外部のメールをGmailに集め、いつものフィルタで整理できることも、このブリッジの大切な目的です。たとえば送信者や宛先、件名を条件に、取引先別・受信アドレス別のラベルを付けるなど、Gmail側で用意したルールを活用できます。複数のメールアドレス宛てのメールをGmailでまとめて管理したい方に便利です。

元サーバーからの取得にはIMAPを使いますが、Gmailへの保存にはGmail APIのメール取り込み機能（messages.import）を使います。GmailへIMAPで単純にコピーする方式とは異なり、通常のメール受信に近いスキャン・分類処理を通す仕組みです。取り込み方式の公式説明

フィルタはGmail側で設定してください。取り込み後にBridgeが元メールの既読・未読状態や出所ラベルを反映するため、すべてのフィルタ操作が通常受信と同じ最終結果になるとは限りません。まず送信者・宛先・件名によるラベル振り分けを試すと、運用に合うか確認できます。複数のIMAPアカウントを取り込む場合は、アカウントごとにBridgeの設定・DB・実行環境を分けます。

取り込み対象は、指定した1つのフォルダ

標準設定では、元メールサーバーのINBOX（受信トレイ）のみを取り込みます。送信済み・迷惑メール・ゴミ箱・サブフォルダを自動巡回する機能はありません。設定の [imap] mailbox で別のフォルダを指定することはできますが、1つの設定で取得する対象は1フォルダです。

元サーバーの振り分けルールや別のメールソフトによって、取得前にINBOXから別フォルダへ移動されたメールは、INBOXを対象とするBridgeでは取り込まれません。

メールが届くまで

  1. IMAPからメールを取得し、元メールの既読・未読状態を確認します。
  2. Gmailへ取り込み、出所ラベルと既読・未読状態を反映します。
  3. 通知を有効にしていれば、設定したntfyサーバーへ新着通知を送ります。

添付ファイルとDriveへの退避

Gmailの添付ファイル制限は、危険なファイルから利用者を守る重要なセキュリティ機能です。一方で、悪意のない業務資料でも、たとえばパスワード付きZIPの中に、さらにZIPなどの圧縮ファイルが入っている構造は拒否される場合があります。詳しくはGmailがブロックするファイルの公式説明をご覧ください。

メールサーバーごとに添付ファイルの受信方針は異なります。Gmail Bridgeが対象とするのは、元のメールサーバーの運用方針で、すでに受信・保存されているメールです。そのメールをGmailへ取り込む段階で添付が拒否されても、本文をGmailで確認し、添付へアクセスする手段を残せるように、Driveへの退避機能を設けています。

この機能を有効にすると、Gmailが添付を拒否した際にGoogle Driveへ添付を保存し、Gmailには本文とDriveリンクを含む軽量版メールを取り込みます。アプリはDriveの共有設定を一般公開へ変更しません。

元サーバーで受信済みであることやDriveへの保存は、ファイルの安全性を保証しません。添付を開く際は、送信元や内容を確認し、利用者・組織のセキュリティ方針に従ってください。

元IMAPメールの削除は設定によって有効になり、取り込み完了後の猶予期間と安全確認を経て実行されます。

About Gmail Bridge

A self-hosted Python tool that imports IMAP mail into Gmail, with optional Drive attachment fallback and ntfy notifications. The Gmail Bridge OAuth app referenced here is for its owner's personal use. Users of the source code must create their own Google Cloud project and OAuth credentials. This is not a hosted sign-in service.
