プライバシーポリシー

このポリシーは、このサイトに対応するGmail Bridgeの所有者による個人運用を対象とします。公開コードを別の方が運用する場合、その方がデータの管理と説明を行います。

取り扱う情報と目的

本人のメール取り込みのため、メール本文、送受信者、件名、添付ファイル、既読状態などを処理します。Google OAuthで許可された権限を用い、Gmailへの取り込み、ラベル・既読状態の設定、取り込み状態の確認を行います。必要に応じてDriveへ添付を保存します。

保存先と外部送信

メールと添付は、本人が認証したGoogleアカウントのGmail・Driveに保存されます。OAuthトークン、設定、処理記録、ログ、バックアップ等は運用者が管理するPC・NASに保存されます。アプリはDriveファイルの共有権限を一般公開に変更しません。

通知を有効にした場合、設定したntfyサーバーへ新着・障害・復旧などの通知を送信します。現在の新着通知には、メール本文・件名・送信者を含めません。各外部サービスでの取り扱いには、それぞれの規約・ポリシーが適用されます。

利用範囲

この個人運用では、取得した情報を広告、販売、AIモデルの学習目的に使用しません。Google APIから取得した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

保持と削除

GmailのメールとDriveファイルは、運用者が各サービスで管理・削除します。NASの記録、ログ、バックアップは設定した保持期間と運用者の管理に従います。アプリの停止や認証解除だけでは、保存済みメール・ファイルは削除されません。元IMAPメールの削除を有効にした場合、取り込み後の猶予期間と安全確認を経て削除します。

アクセスの解除

Googleアカウントの接続管理からアクセスを取り消せます。アプリを停止し、ローカルの認証情報を削除することで継続アクセスを停止できます。保存済みデータやバックアップの削除は別途行ってください。

問い合わせ

個人用OAuthアプリについては、OAuth同意画面に表示されるユーザーサポートメールへお問い合わせください。公開コードについてはGitHub Issuesをご利用ください。認証情報・メール内容などの秘密情報は投稿しないでください。

English summary

This policy covers the owner's personal deployment. Mail is processed to import it into the authorized Gmail account; rejected attachments may be stored in Drive. Credentials and operational records are stored on the owner's devices. Optional ntfy notifications report delivery or operational events; new-mail notifications omit message bodies, subjects and senders. Data is not used for advertising, sale or AI training. Google API data use complies with the Google API Services User Data Policy, including Limited Use. Revoke access in your Google Account settings and separately delete retained data where required. Other deployments are managed by their respective operators.
